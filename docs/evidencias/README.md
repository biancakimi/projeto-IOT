# Evidências de Funcionamento do Sistema — `docs/evidencias/`

Esta pasta armazena as fotos, capturas de tela e vídeos curtos exigidos para comprovar o funcionamento prático de cada etapa na entrega final:

1. **Validação de Circuito em Protoboard:** Fotos e logs do Monitor Serial comprovando leitura do DHT11, LDR e acionamento dos servos/relés.
2. **Comunicação LoRa 915 MHz:** Prints do envio de pacotes do Nó Estufa e recepção com RSSI/SNR no Nó Gateway.
3. **Placa de Circuito Impresso (PCI):** Fotos do processo de confecção, soldagem dos componentes e teste da placa montada.
4. **Etapa de Nuvem (MQTT, Node-RED, Banco de Dados e Site Web):** Prints dos fluxos ativos no Node-RED, registros salvos na tabela `historico_estufa` e telas do site de gerenciamento remoto.
