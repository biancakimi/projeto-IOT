# Projeto e Impressão de Encapsulamento 3D — `encapsulamento_3d/`

Esta pasta é destinada aos arquivos de modelagem 3D (`.STL`, `.STEP`, `.FCStd` ou `.SLDPRT`) do **Desafio Extra: Projeto e Impressão de Encapsulamento (+1,0 ponto)**:

* Case protetor ventilado para a PCI do Nó Estufa (com aberturas para circulação de ar no DHT11 e janela translúcida para o LDR).
* Suporte mecânico para fixação do servomotor e articulação das aletas da persiana.
