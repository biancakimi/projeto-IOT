# Projeto de Placa de Circuito Impresso (PCI) — `pci_hardware/`

Esta pasta armazena os artefatos obrigatórios referentes à etapa de **Projeto e Confecção da Placa de Circuito Impresso (PCI)** (3,0 pontos na avaliação):

* `esquematico_pci.pdf`: Diagrama esquemático elétrico completo exportado do KiCad / EasyEDA.
* `layout_pcb_gerber.zip`: Arquivos Gerber e visualização das trilhas (Top/Bottom Layer) da PCI.
* `lista_materiais_BOM.md`: Lista de componentes (Bill of Materials) utilizados na montagem.
